# WEB-CREATORS: DIGITAL EMPIRE

**BUILD YOUR DIGITAL EMPIRE.**

A cross-platform business simulation and website creation game: start as a beginner founder with 500 virtual coins, open fictional businesses, design their websites, complete missions and learn real web and business skills along the way.
